# Wall and floor compound type legend (#172)

Baseline 0c523067c4313bd9e8c3898be4ffd32d874463d7. GitHub #172 asks for one sample per compound wall and floor type in use, with material, thickness, function, and a width check. The current am-reference-samples skill defines a sample view as a Revit drafting view and covers line, text, dimension, filled region and fill pattern types (SKILL.md:8–14). The material audit reads layer material IDs by type (skills/am-material-audit/scripts/read_materials.py:178–204). It does not identify types in use or report ordered layers and type widths. This feature will give the user both a standalone preview and a native drafting-view legend through am-safe-change.

1. Read host-project wall and floor instances through filtered collectors, deduplicate by type ID, resolve exact type UniqueIds, and count instances. Exclude unused types. Report wall and floor instances whose types have no compound layers. Read ordered layers using GetCompoundStructure and GetLayers, with material ID/name, layer function, width in internal feet and variable-layer index. Keep zero-thickness membranes. Treat material ID -1 as By Category. Show unresolved positive IDs that do not resolve to DB.Material, and unexpected negative IDs. Do not substitute a material name. Read nominal WallType.Width or FloorType Default Thickness independently of the layer list. Preserve each type's ID and width as well as the layer list. For a vertical structure report the type width, nominal grid width and nominal layer sum as distinct measurements. Compare the sampled layer sum with the simple slice width.
