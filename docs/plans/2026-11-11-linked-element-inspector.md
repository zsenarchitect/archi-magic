# Linked element inspector (#173)

Base 0c523067c4313bd9e8c3898be4ffd32d874463d7. GitHub #173 asks to pick or name a linked element, report its linked-file ID, category, parameters and link, and select it in the host view. The current health report inventories link instances and potential visibility (skills/am-model-health/SKILL.md:66–75). The structural reader resolves a chosen host link and reads selected linked IDs (skills/am-issue-board/scripts/read_structural_geometry.py:117–134). Neither provides the requested element inspector and host selection. pyRevit navigation links are scoped to the active document, so use the linked-reference API instead of constructing a pyRevit navigation payload.

1. Add a focused query script to am-model-health. Inspect either one already picked linked reference, one exact linked element ID, or one exact element name in a selected link instance and category. The user can pick visually with Tab in the active host view. Read the picked reference from Selection.GetReferences. Resolve Reference.ElementId in the host and Reference.LinkedElementId in its loaded link document. Name lookup uses a category collector and exact name matching. Present ambiguous results with linked-file IDs and ask the user to choose. Reject unsupported, unloaded, nested, host-only or stale references with an actionable message.
2. Return the link instance ID and name, linked document title, element ID and UniqueId from the linked document, category, element name and requested parameters. Do not return model path strings. Preserve 64-bit IDs as decimal strings. List ordered instance parameters by default. Accept explicit parameter names for additional or nonvisible fields. Preserve duplicate-name parameter entries with their IDs. Report typed values and unset or unsupported state. Cap search at 5,000 elements, eight seconds, 20 named parameters, 40 returned parameter entries, 2,000 characters per text value, and 128 KiB per result. Mark incomplete searches without choosing a match. Mark value truncation explicitly.
3. Return an exact host-view selection target for a uniquely identified element. Bind it to active host project identity, host view UID, link instance UID, link project identity and linked element UID. Recheck those identities immediately before selecting. Use Reference.CreateLinkReference and Selection.SetReferences with a typed .NET list. Read GetReferences afterward and verify both IDs. Restore the prior selection on mismatch when possible and report its outcome. Use the current host view and make no Revit model transaction. A separate user-confirmed selection command prevents unexpected UI changes when inspecting by name.
4. Use official [Autodesk linked references](https://help.autodesk.com/cloudhelp/2025/CHS/Revit-API/files/Revit_API_Developers_Guide/Advanced_Topics/Linked_Files/Revit_API_Revit_API_Developers_Guide_Advanced_Topics_Linked_Files_Revit_Links_html.html) and [selection methods](https://help.autodesk.com/cloudhelp/2024/PTB/Revit-API/files/Revit_API_Developers_Guide/Basic_Interaction_with_Revit_Elements/Selection/Revit_API_Revit_API_Developers_Guide_Basic_Interaction_with_Revit_Elements_Selection_Changing_the_Selection_html.html). Use existing pyRevit run_query and ASCII JSON result patterns. Document the supported host versions and exact script inputs. Test picked references, name ambiguity, two placements of one file, coincident IDs in host and link, Unicode and exact IDs, no selection on stale/unknown scope, and failed selection restoration. Native acceptance uses one disposable host model and a linked RVT with a known element. Compare the reported ID to a direct lookup in the linked file. Exercise picking, name search and selection readback in the host, with a repeated-link placement as a control. Record Revit version, engine and source revision.

Dependencies are Revit 2024–2026 and the pyRevit runtime. An approved disposable host is needed for native acceptance. Revert the PR to remove the feature. Select the original references to undo a UI selection.
