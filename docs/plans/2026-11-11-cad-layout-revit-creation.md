# Guarded Revit creation from a linked DWG

Issue [#166](https://github.com/zsenarchitect/archi-magic/issues/166) asks for walls and doors from mapped DWG layers. Its title and RFC 001 also cover rooms. The [geometry plan](2026-11-09-cad-to-bim-preview.md) defines the source, tolerances and native acceptance. At local baseline `6ce2533`, `read_linked_cad_layout.py` returns a measured snapshot, a verified type mapping and an evidence digest. `cad_layout_preview.py::propose` returns walls, door locations and room outlines. The confirmed gap is a Revit write path with native readback. Neither script opens a transaction.

## Preview and scope

1. Keep the portable CLI and output format. Place the native entry point with the installed DWG reader and run it through am-safe-change. Reuse `propose` with fresh evidence. Require the mapped request, source digest, exact active floor-plan view and phase, explicit wall height and room-bounding choices, and hand and facing for each door. Canonicalize the executable plan to sorted-key ASCII JSON before hashing. Display-only notes and ownership decorations stay outside that digest. Live ownership checks still run on both executions. This normalizes XY tuples and their wire arrays. Show all unresolved items and block Apply when any remains. Recompute the plan at both executions. Transport only the bounded request and approved plan digest plus the normalized dry-run receipt for real apply. Keep the display artifact local. Cap request and normalized receipt at 128 KiB each and the full preview at 2 MiB. Recover complete runtime results with `get_run` and reject truncated or incomplete envelopes. Qualify the maximum supported request and receipt through the installed runtime before enabling writes.
2. Use document-wide Revit category collectors for walls, doors, rooms, room separation lines, and room-bounding elements such as columns, floors, ceilings, roofs and links. Check transformed extents and phase, including adjacent rooms above and below when their vertical extents intersect the proposal. Treat bounding boxes only as a broad phase. Check existing opening and wall geometry, room boundaries, and independent source IDs. Refuse unknown extents, unsupported intersecting link or design-option geometry, and incomplete scans. Keep observed IDs in the before/after basis. Supply only explicitly permitted existing writes such as required symbol activations to `ownership_ids`. Recheck both ownership and central update state where applicable. Do not alter the DWG, existing geometry, view properties, or project defaults.
3. Mark an approved room edge as wall-supported only when one proposed wall finish face supports its full span within tolerance. Create separation lines for the remaining edges. Block partial, competing or uncertain support, and block shared or touching room loops under the existing planner contract. The read-only preview predicts enclosure and reports existing placed room boundaries. Revit's phase-specific `PlanTopology` requires a modifiable document, so qualify the resulting circuit after regeneration in the rollback-capable transaction. Show wall heights, boundaries and counts for all four object kinds.
4. Scan provenance before checking manual collisions. Store a geometry-independent lineage key for the host project, link instance, level and selected layer names and roles. Within that lineage, compare the complete existing piece-key set against the new plan. A shifted or reloaded DWG cannot hide a stale set by generating different piece keys. Block overlapping lineage scopes with different layer groupings until reconciled. Reuse the room-finish schema pattern with a CAD-specific ID. Each element record binds a stable source key, own UID, expected source geometry, observed native geometry and plan identity. Source keys cover document, link instance, level, role and source geometry. Keep them separate from freshness digests and type version GUIDs. If all records are exact, exclude only those identified elements from the conflict scan and return a no-op after checking current surrounding geometry. Copied, edited, stale or partial tags and manual conflicts block. Do not repair or adopt existing elements. On the read-only replay after Keep, read a fresh digest. Compare source geometry, mapping and types to the kept receipt. Reconcile only the exact observed transition from inactive to active on approved symbols. Record and compare their native UID, width, family identity, placement type and canonical type parameter state before and after activation. Any other difference or unmeasurable state blocks. Other changes require review. Test an initially inactive symbol followed by a no-op.

## Native transaction and verification

1. Reuse the transaction group and DocumentChanged pattern from `room_finish_placement.py`, with the rolled-back dry-run receipt pattern from `place_sheet_views.py` and `sheet_placement_preview.py`. Verify effective ask policy before dispatching either modify call and qualify that the runtime binds ask at request acceptance. Disable real apply where that precondition cannot be proved. Preview and confirm before running `run_modify` with `dry_run: true` and internal dry-run mode. Recover and verify the complete rolled-back runtime envelope and distinct run ID outside Revit. Pass the bounded verified receipt, run ID, and runtime envelope digest to the real invocation. Verify the post-dry baseline in a fresh query. The real entry point rejects missing, malformed or mismatched dry-run evidence before mutation. Check the exact plan and source digests and native observation fingerprints. Compare the real fingerprint with the approved dry run inside the group, before assimilation. Require the outer runtime to record user Keep or Discard. Treat inconsistent mode before mutation as a stop. A policy mismatch reported after execution leaves the outcome unresolved and requires independent readback. Use transaction-scoped `IFailuresPreprocessor` to record failure IDs and severity and return `ProceedWithRollBack` for unapproved failures. Keep failures visible and do not delete warnings to continue. Treat Pending or an unverified rollback as unresolved. Qualify CPython callback binding and a seeded native warning on the disposable host.
2. Use typed `Wall.Create` for vertical Basic walls and disable both end joins. Validate the actual major interior and exterior planar faces from `HostObjectUtils.GetSideFaces` at both ends of the reviewed span. Check the resulting centerline, width, level, vertical extents, bounding and joins. Exclude unsupported split or nonplanar profiles unless actual measured spans remain complete. Activate only reviewed inactive door symbols and measure that permitted state transition. Place a door using `NewFamilyInstance(XYZ, FamilySymbol, Element, Level, StructuralType)` on its exact new wall and level. Verify location and Z convention at a nonzero project elevation, host, type, level and flips. Use occupied intervals from the actual wall solid and horizontal probes through its thickness and along its axis at a reviewed Z to verify the complete cut span against the marker tolerance. Test the case where a hosted door is returned with no effective cut. Block inconclusive geometry.
3. Create exact separator curves via `NewRoomBoundaryLines` on a checked horizontal sketch plane with the approved level floor plan. In the active transaction, regenerate and inspect `PlanTopology[level, phase]`. Require one unoccupied circuit whose native interior point is within the reviewed contour. Treat circuit area as an optional cross-check when the measurement basis is known. Create a phase-specific unplaced room with `NewRoom(Phase)` and place it with `NewRoom(Room, PlanCircuit)`. Move the location to the reviewed seed only after the boundary matches. Verify the exact phase, level, seed containment and complete explicitly requested Finish boundary including source wall and separator IDs after regeneration. Independently calculate finish area from the native loop and compare to the CAD contour in square millimetres with an explicit area tolerance. Report Room.Area and its native basis separately. Leave project settings unchanged. Block uncertain room or circuit matches. Do not use the phase-less point creation overload.
4. Snapshot existing affected room IDs, areas, native boundary geometry and source IDs. Measure phase-specific circuits inside the inner transaction before mutation and after regeneration. After inner commit, use read-only room APIs to compare boundaries, areas and source IDs while group rollback remains possible. Include adjacent and vertically intersecting rooms and transformed room-bounding links. Check created and demolished phase for each boundary piece. Include all phases where walls or separators are effective, including later phases for undemolished walls and all applicable phases for phase-neutral separation lines. Unknown phase scope or topology blocks. Use the same set of phases for the in-transaction topology comparison and the post-commit geometry comparison. Also block any existing element delta outside the exact allowed symbol activations and any unexplained added element. Permit a new sketch plane only when used by the new approved separator curves. Bound candidate and provenance visits to 5,000 each, observed rooms to 250, native circuits to 500, event IDs to 2,000, room boundary edges to 5,000 and the whole review read to a 15-second soft budget. Stream scans and stop on the first overflow. Verify all created elements before closing the group. The dry and real observation fingerprints use source keys, native geometry and allowed effects, independent of allocated IDs. Verify the full unchanged baseline after Dry Run, Discard and late failure. After Keep, read new and affected existing elements again in a separate query. Reconcile provenance and require no changes on replay.

## Acceptance and dependencies

- Run local checks first. On a disposable saved Revit 2026 host with pyRevit CPython, independently verify a read-only receipt against known DWG layer membership, transformed points and actual mapped widths before the first native apply probe. Include translated and rotated geometry on a nonzero level and a reflected nested control. Then verify a rollback-only dry run, fresh unchanged readback, an ask-policy Discard and fresh unchanged readback, and an ask-policy Keep with exact fresh readback. Replay for no changes. Include a hosted door, an initially inactive symbol, a room bounded by both a wall and separator lines, a wrong-phase circuit, touching room loops, existing overlap, an existing room in a later phase, partial provenance, a moved source that no longer overlaps its prior output, and changed level and type.
- Qualify transaction nesting and hosted-door Z on the exact installed runtime. Autodesk documents [hosted family placement](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/168d4c67-73dd-d7c8-4969-12846eeaddfa.htm), [phase-specific topology](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/215a0d2b-0f9f-1532-cb15-d1f6a2af029a.htm), [phase-specific room placement](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/9ceb1869-e41b-8a3f-557c-0b13eb062e0b.htm), [major wall faces](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/589b9363-c2cc-52d9-6ba1-fc8e8f912b27.htm), and [failure preprocessing](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/0647c18e-c1ad-60b8-d993-cb464b7b676e.htm). The existing floor-drain recipe's level-relative Z behavior uses a different overload.
- Exercise the normal entry point in the local suite. Run positive and negative controls for JSON transport, source drift, independent existing-room topology, no effective door cut, event mismatch, changed real-run geometry and late failure. Use native Revit for Keep/Discard and geometry claims. Publish with `Refs #166` after native acceptance and pass exact-head CI. Verify the exact merged revision on the disposable fixture before closure. Roll back disposable changes with Discard or Undo and the repository change with a merge revert.
- Leave AutoCAD writes, Revit-to-DWG export, inference from arbitrary curves and automatic repair of competing existing geometry to their separate issue scope.
