# Split walls, columns and floors for issue #151

[Issue #151](https://github.com/zsenarchitect/archi-magic/issues/151) asks for selected walls and columns split at each level and for floors split by grid or line. The resulting instances must retain the original type and instance parameter values. Baseline main is `0c523067c4313bd9e8c3898be4ffd32d874463d7`. The baseline search found no split recipe in am-safe-change or am-model-health. The issue proposes a feature and supplies no filed failure diagnosis. The remaining behavior hypotheses below require current native evidence.

## Read and preview

Read the requested Level or Grid from the same saved document. For a drawn line, bind its native identity and curve. Use Level.ProjectElevation in the saved project frame and verify alignment with model geometry. Sort and deduplicate reviewed cut elevations or lines, and require them to intersect the native interior. Show all rejected and supported rows, piece extents, old and retained type, preserved values, geometric/derived differences, and the explicit original-element disposition. A blocked or incomplete read has no executable plan.
2. Compare parameters by stable native definition identity and storage type. Use shared GUIDs and use definition IDs and built-in identifiers in the bound document. Record typed String, Integer, finite Double and signed decimal ElementId values including sentinel values. Record HasValue separately from zero or empty text and record read-only state. Reject unreadable values, duplicate or missing definitions, and unexpected extra definitions on any result piece. ClearValue is limited to supported HideWhenNoValue shared parameters. Reject a defaulted parameter whose original unset state cannot be restored. Preserve units by using raw internal values. Verify every resulting part against the source for each non-geometric instance field. Reject a segment when an incompatible read-only business parameter or unique value cannot be preserved. Classify only documented necessary differences, such as newly assigned element identity, length/area/volume, and actual base or top constraint values. Show those changes as separate rows and block any exception whose mapping cannot be justified. [Autodesk parameter storage types](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-API/files/Revit_API_Developers_Guide/Basic_Interaction_with_Revit_Elements/Parameters/Revit_API_Revit_API_Developers_Guide_Basic_Interaction_with_Revit_Elements_Parameters_Parameter_html.html)

Measure cap and cap-plus-one fixtures and reduce the limits if the observed bridge envelope requires it. Treat native calls whose elapsed time or output completeness cannot be verified as unresolved. Refuse unsupported links, groups, design options, worksharing updates, in-place families and constraints whose preserved effect cannot be measured. ## Execution and acceptance

- Preview and approval precede the trial. First qualify native transaction nesting and ask mode on disposable controls, then run each exact recipe with run_modify dry_run:true. Use a whole-batch rollback scope. Capture document-bound, operation-tagged DocumentChanged events through inner commit and terminal outer rollback. Record pre-rollback trial effects separately from terminal net effects. Use native event operation and transaction names to distinguish commits from rollback. Qualify the installed bridge dry-run receipt semantics and reconcile all added, modified and deleted IDs to the appropriate full untruncated evidence. Treat Pending, foreign-document events, unknown effects, missing telemetry or an incomplete receipt as unresolved. Block retry and replay until terminal rollback and independent readback. Verify type and parameter inventories while all new instances exist and reject extra additions, changes or deletes, including generated same-category and late effects. Reread the saved project after rollback from a separate query and prove the original instances, parameters, dependencies and geometry are restored, unrelated controls are unchanged and every temporary piece is absent. Include a forced mid-batch failure and a fixture with an unpreservable parameter. A fixture that passes only by skipping a source is incomplete.
- Qualify the installed bridge's native Keep and Discard on a disposable fixture before enabling a real write. Bind replay to the exact reviewed scope, recipe and preview and recompute them from fresh evidence. Require the installed bridge to bind effective ask to the specific replay invocation or enforce ask inside that invocation before any mutation. Keep replay disabled until a disposable policy-switch control proves that auto or unknown policy aborts with an unchanged model. Verify approval:user in the full bridge receipt. Compare exact original affected and deleted ID/UID sets and require a bijection from each trial and replay run’s newly generated IDs to stable signatures made from source identity, ordered extent, type and preserved parameters. Include native sketch internals in the effect mapping. Verify each result and its complete effect closure. Discard must restore the baseline. After Keep, independently reread every new piece, retained original, approved deletion and unrelated control. Match exact scope, geometry, dependencies and parameter inventory. Show the named Revit Undo entry if verification fails.
- Record current Revit and bridge versions, exact source and tested revision, cut stations, expected and measured pieces, stable type identities, typed instance parameter comparisons and full change IDs. Acceptance requires zero unexplained parameter mismatches and zero unapproved element effects in the wall, both column categories and floor fixtures. Set independent geometry and parameter expectations before the reader runs. Test multiple interior levels on one wall and both column categories, a native Grid and independently picked Line for separate floors, and repeat and stale runs that reject or explicitly do nothing with zero model effects. Include coincident/end cuts, rejected dependencies, boundary controls and rollback. Use approved disposable fixture RVTs. Keep model values, identifiers, paths and native receipts private and publish sanitized assertions with host version and commit only. Run repository tests and both GitHub CI jobs on the exact head, then verify the installed merged revision before closure.
- External dependencies are a licensed Revit host, an approved disposable project and supported native bridge with an observed approval mode. The open API questions are the geometry used to normalize vertical column cuts, wall regeneration and constraint fidelity, and whether retaining a floor's ID through a profile edit is possible with the chosen transaction boundaries. Use direct native readbacks to resolve them before enabling each operation. No automatic cuts inferred from all levels in the model, no automatic deletion, and no use on production models during qualification.
- Roll back the implementation by reverting its isolated commits. Roll back trial effects before leaving the trial, and use the named Revit Undo entry for a kept mismatch.
