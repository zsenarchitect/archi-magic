# Confirmed product specification to Revit family (#181)

Baseline main 469282d13e78a8d19f360990de0d17f1bc7dc68b. Issue #181 asks to read product dimensions and connector or clearance data from a PDF, confirm a table, build a parametric family with source provenance, and load and place it under Keep/Discard. Filed gap confirmed: am-markup-intake/scripts/document_tables.py extracts bounded PDF table rows and coordinates; am-import-from-manufacturer-rvt/SKILL.md copies system types from an open RVT and explicitly excludes loadable RFA families. am-safe-change/SKILL.md defines active-document, preflight, ownership, dry run, approval and readback.

1. Reuse the local PDF worker. Map explicit table rows and columns to width/depth/height, a sourced clearance envelope or connector data, and optional product fields. Keep original text, file basename, PDF page/table/row, and file digest. Normalize explicit supported length units into decimal millimetres, rejecting mixed or missing units, malformed numbers, unresolved ranges and absent mandatory dimensions. Never interpret scan pixels or guessing as data; report unsupported layouts for a user-verified table mapping. Source may span multiple selected pages. Show source and normalized values in a numbered preview. Keep PDFs and reports local.
2. Accept a separate explicit confirmation document bound to the exact preview and source bytes. Require a decision for every displayed field and provenance for any corrected value. Reject incomplete decisions, duplicate keys, nonpositive dimensions, nonfinite values and clearance that cannot surround the box. Output a declarative artifact, with dimensions and clearance typed and grouped by units and source pages. Separate table confirmation from model authorization. No host changes from the local CLI.
3. Use a disposable, local, non-hosted Generic Model family template in the Revit version under test. Family authoring takes place with a family document active and the project closed or inactive. Use Autodesk Revit 2026 FamilyItemFactory.NewExtrusion for a rectangular solid and, when present, a separate clearance envelope subcategory with non-cutting geometry. Constrain the box profile to named reference planes and label dimensions with FamilyManager length parameters, and associate height with the extrusion parameter after confirming the actual built-in ID. Bind the same pattern to the clearance envelope. Preserve product identifiers, connector specification data and PDF name/page as text parameters. A physical MEP connector is not needed for a box-level Generic Model; report connector data without inferring domains, system types or geometry. Use am-safe-change in the active family for dry run and Keep/Discard; user saves to a new local RFA after readback. This avoids modifying a second document behind the guard.
4. Open a disposable project, preflight the identity and pinned file digest, placement level and location, RFA content and family/type name collision. Test filename-based project Document.LoadFamily or the narrower LoadFamilySymbol overload followed by NewFamilyInstance in the same guarded project operation. Autodesk's separate family-document LoadFamily/EditFamily path has different transaction constraints. Abort on false load, duplicates, missing type/level, doc drift or ownership. Reuse the existing dry-run rollback and Keep/Discard model authorization; independently reread family parameters, placement and geometry after Keep. If the host cannot roll back both project writes together, leave the operation unqualified until a safe supported route is proven.
5. Run focused local tests on synthetic PDF tables (imperial and metric, malformed units, exact source page, duplicate keys, stale document and decisions, empty clearance, and correct review). Prove the real workflow on a disposable Windows/Revit installation: extract from a 2-page synthetic equipment PDF, reject a blank/stale confirmation, confirm dimensions, compare measured family extents against the table and flex width/depth/height and clearance, then verify discarded family and project runs leave their respective models unchanged and Keep produces one family/type and one instance. Check PDF basename and page parameters. CI validates the offline layer; the native checks and ready-to-use host path are required for closure.

Assumptions and dependencies: approved Windows/Revit host, local templates, pyRevit transport and a disposable test project are external dependencies. The template must be proven non-hosted and compatible. Autodesk Revit 2026 API references for NewExtrusion, FamilyManager, EditFamily and filename-based LoadFamily define separate APIs; live transaction/constraints tests still required. Measure exact dimension and coordinates in mm after converting at the API boundary. No project uploads, OCR service, external content download, production project writes, implicit approvals, or editing existing families. Rollback: discard model changes in host, undo a kept test transaction or close the disposable copy; leave any pre-existing RFA untouched; revert a merged code change if needed.

Record extracted cell text (outer whitespace normalized), zero-loss millimetre value, one-based page/table/row/column and SHA-256 of the snapshot. A mapping names the field, position and, if the cell has no unit, an explicit unit from the source label. Confirm by rehashing the local source and by recomputing the expected preview from the supplied mapping and the current bytes. Use strict JSON duplicate-key rejection and exact preview-byte digest as in narrated_recording_cli.py. All displayed fields need accept or a sourced correction. Correct a source locator/value by generating a new preview and reviewing it again. Accept decimal mm, cm, m, in and ft with no implicit units, fractions, ranges, exponent notation or mixed units. Positive equipment dimensions are 1–30,000 mm; each side's optional clearance offset is 0–30,000 mm and the combined envelope cannot exceed 60,000 mm on any axis. Retain connector and product data as bounded literal text, with no paths or executable fields. Report selective-text/table limits clearly. ## Rollback-only family geometry probe

Use a saved disposable local Revit 2026 Generic Model family with no existing extrusions. Open the family as the active document. Run `probe_spec_family_box.py` through `run_query` with `{"mode":"read"}` and save the baseline. Review the confirmed dimensions and fixture. With `run_modify` and `dry_run: true`, pass the exact baseline, the confirmed specification UTF-8 text as `specification_json`, and the SHA-256 of those bytes as `specification_sha256`. The probe creates a rectangular solid, measures the model-space bounds and rolls back. Check the receipt and independently reread the fixture. This exercises the active-family context and native dimensions before adding parameter constraints, clearance, provenance, and project load and placement.

## Rollback-only project placement probe

After independently inspecting the saved RFA, pin its SHA-256 and choose the exact family and type names. Open the disposable local Revit 2026 project with a nonzero placement level. Call `probe_spec_family_placement.py` through `run_query` with `mode=read`, `level_id` and `family_name`. Review the baseline and level-relative XYZ. Then call the same script through `run_modify` with `dry_run: true`, passing the complete `baseline`, `type_name`, absolute local `rfa_path`, `rfa_sha256` and `placement_level_relative_ft`. The script loads from a temporary copy of the reviewed bytes, activates the exact type, and verifies the world location and level. It rolls back and checks the created IDs and the original family inventory. Rerun the independent baseline read after the probe. Use this for native load and placement qualification before testing the Keep/Discard production workflow.

For the constrained box probe, also pass `constraint_view` with the decimal `id` and `uid` of the fixture's zero-elevation family plan. The probe constrains four side faces to reference planes, labels the two plan dimensions, and associates the extrusion end with a height parameter. It increases each dimension separately, verifies that only that axis changes, restores the reviewed box between trials, and verifies that rollback removes the added elements, type and parameters. Capture the Revit build and engine in the receipt. Native flex qualification remains a prerequisite for family Keep/Discard.

The constrained probe also writes PDF source file, pages, SHA-256, product and variant to the candidate type. Confirmed connector and product fields are stored as text parameters with separate prefixes. The probe verifies that each value agrees with its source row before opening a transaction and rereads the actual type text after the flex tests. Rollback must restore the original type and parameter inventory. The source basename and pages remain available in the receipt for comparison with the confirmed table.

When the confirmed source includes all six clearances, the constrained probe builds a separate solid in the Equipment Clearance subcategory. It anchors the lower corner at the reviewed left, front and below offsets and drives its extents from the equipment dimensions plus the opposing clearances. The probe measures both boxes before flexing, after each individual axis change and after restoring the original dimensions. It verifies that rollback removes the clearance geometry, subcategory and temporary parameters.
