The baseline is 16357df4e9a6bf7476585c74b08e526715c4a876. The issue requests sheet numbers, names, title block types and parameters from an Excel or chat list. The filed gap is confirmed. `read_sheets.py` has a sheet inventory, including placeholders, and a separate revision inventory. `apply_sheet_revisions.py` edits revision membership. ## Input and plan

- Accept a reviewed JSON row list. For Excel, take the existing bounded `document_tables.py` XLSX extraction with a selected worksheet and header. This reader rejects formulas, errors, merged cells and mismatched row widths. Preserve its workbook/sheet/source-row references in local review. A chat list maps to the same JSON fields. Sheet numbers stay strings. In the bounded XLSX extraction, validate the mapped Number column as literal text on the actual worksheet cell before `cell_text` drops its type and number format. Preserve text `001` and reject numeric `1` displayed as `001`. The original workbook probe demonstrated this loss in the current reader. A blank parameter cell means omit the assignment. An explicit empty string can be requested through reviewed JSON only and must have a matching native readback. Hash the exact bounded workbook bytes parsed and bind the digest, worksheet, header row, mapping and normalized row list to the approved plan. Verify workbook identity and digest before both runs. Use an opt-in XLSX extraction policy so other table callers keep their current output.
- Read all sheet numbers, including placeholders, and exact loaded title block type IDs, UIDs and labels from the saved Revit document. Select by ID and review the labels. Identify title block types by native category and FamilySymbol. Reuse the collector pattern. Leave the legacy integer-ID/escaped result unchanged. Emit a separate ASCII JSON creation snapshot with decimal IDs, UIDs and document identity built from ProjectInformation UID and a saved-path hash. Require a complete, bounded census. Use Unicode NFC plus case-folding for conservative collision review, and retain exact text for the native setter and readback. Reject blank, padded or documented prohibited sheet-number characters up front and let the Revit setter enforce native restrictions. Flag duplicate requested keys by source row. Classify an existing exact sheet number as already matching only after verifying its number, name, title block and requested instance values. Report placeholders, case-equivalent numbers and mismatched or unreadable values as conflicts. Existing sheets remain untouched. Other rows can proceed after review of the skipped rows.
- Treat sheet and title block instance parameters as separate targets. Resolve shared parameters by GUID, reviewed built-ins by exact enum identity from a permitted metadata set, and project parameters by same-document ParameterElement ID plus UID and `GetDefinition`. Reject GlobalParameter definitions and globally controlled targets. Deduplicate aliases by resolved owner and parameter ID. Never use a localized display name to resolve a write. Reserve sheet name and number on both scopes, and exclude structural fields that can affect placement or type. Match storage and spec before assignment. Require the yes/no spec for booleans and signed 32-bit integers for integer values. For Double validate `GetDataType`, `IsMeasurableSpec`, and `IsValidUnit` before `ConvertToInternalUnits`. Read back `AsDouble` in internal units with absolute tolerance 1e-8 and relative tolerance 1e-10. Permit ElementId values only for explicitly supported reference semantics and a same-document reference resolved by ID, UID and expected category. Reject read-only, type-level, ambiguous or invalid destinations. Do not bind new parameters or modify a family. Preview the requested values with scope and units. A fresh disposable dry run verifies the parameters on the actual created instances, including unused title block types with no existing instance for comparison.
