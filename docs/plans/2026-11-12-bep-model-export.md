# Read-only BEP model exports for #229

Issue #229 asks for one live Revit facts block, one complete view-note export in reading order with headings, and a local DOCX mismatch check. The inputs are the selected Revit document and view and a user-supplied DOCX. The outputs are local JSON and a human-readable report. This workflow does not edit Revit, the DOCX, or another agent's session.
