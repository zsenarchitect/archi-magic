# Review and change sheet revisions

Select one to 30 real sheets in a saved project. Choose one project revision and whether to add or remove it. Save or sync before reading.

1. Call `get_context` and `get_skill("revit-scripting")`. Run `scripts/read_sheets.py` with `run_query`. Use inputs such as `{"revision_sheet_ids":["101","102","103"],"revision_ids":["123"]}`. Include the target revision ID even when it already appears on the sheets. Save the complete response as `read.json`.
2. Decode `snapshot_json` to report clouds by sheet and revision. Show each cloud's comment and whether Revit schedules it. Flag each cloud with `revision_on_sheet: false`. Revit can associate a cloud with a sheet even when the cloud does not appear in its revision schedule.
3. For a change, save an intent such as `{"operation":"remove","revision_id":"123"}` as `intent.json`. Run `python scripts/sheet_revision_preview.py read.json intent.json > preview.json`. Check ownership and show the preview as described in am-safe-change. Review the manual checkbox and effective schedule separately. A scheduled cloud can keep a revision on the sheet after the checkbox is cleared. Stop if no sheets need changes.
4. Confirm the preview. Run `scripts/apply_sheet_revisions.py` with `run_modify` and `dry_run: true`. Set `workspace` to the skill's scripts directory. Pass `{"preview_path":"C:/work/preview.json"}` on the Revit host, or pass the complete preview as `{"preview": {...}}`. Save the complete response as `dryrun.json`. Keep the pyRevit run metadata and its top-level change record.
5. Run `python scripts/sheet_revision_preview.py dryrun.json preview.json --check-dry-run`. Report the revision numbers and side-effect counts. Stop if the check fails. Follow am-safe-change if the check reports extra categories.
6. Repeat the original read query and save it as `fresh.json`. Run `python scripts/sheet_revision_preview.py fresh.json preview.json --check-baseline`. Stop if the dry run left changes, the model changed, or the ownership check blocks a target.
7. Run the same approved preview under the current policy. Under `ask`, review the change in Revit and choose Keep or Discard. Under `auto`, get the second approval after the dry run before applying.
8. After Keep, repeat the original read query. Run `python scripts/sheet_revision_preview.py kept-read.json preview.json --verify`. Compare the returned revision numbers with the dry run and the sheet schedules. After Discard, repeat the baseline check. Follow the sync hand-off in am-safe-change.

To check the cloud report in Revit, use three test sheets. Include a sheet with a manual revision only, one with a visible scheduled cloud, and one with a cloud Revit associates with the sheet but does not schedule. Compare the report with each sheet's Revision Schedule, Revisions on Sheet settings, and the cloud's Comments property.
