# Standardize family thumbnails

Use a disposable Revit session to qualify this workflow. The writer needs a Revit build with unlocked saved-orientation support. Work on one staged family at a time.

1. Create separate local source, staging-parent and output folders. Keep the staging parent in your private user directory. Review the family names with `python skills/am-model-health/scripts/stage_family_previews.py inventory C:/work/library`.
2. Stage only the reviewed names. Run `python skills/am-model-health/scripts/stage_family_previews.py stage C:/work/library --staging-parent C:/work/private-stage --output C:/work/exports --family "Example.rfa"`. Repeat `--family` for each selected file. Keep the manifest local.
3. Run `python skills/am-model-health/scripts/stage_family_previews.py verify <manifest-path> --family "Example.rfa"`. Open that staged copy in Revit. Select an uncropped orthographic 3D view if one is available. Call `get_context` and `get_skill("revit-scripting")`. Run `skills/am-model-health/scripts/read_family_preview.py` with `run_query`. Use the two fields from `revit_inputs`. Save the full query response as `read.json`.
4. Review the observed solid geometry. Save `{"view_type_id":"123"}` as `intent.json` using the reviewed 3D view type ID. Use `python skills/am-safe-change/scripts/family_preview_plan.py read.json intent.json > preview.json`. Render the preview. The preset uses an isometric camera, Shading, and a light gray background. Reuse a dedicated view only with a prior `reuse_receipt` containing `view_uid`, `family_uid`, and `saved_file_sha256`. Stop if the preview has no steps.
5. Confirm the preview using am-safe-change. Recheck the staged family and policy. Run `skills/am-model-health/scripts/apply_family_preview.py` with `run_modify` and `dry_run: true`. Set `workspace` to `skills/am-model-health/scripts`. Pass `{"preview": {...}}` with the complete preview. Save the full response as `dry-run.json`.
6. Run `python skills/am-safe-change/scripts/family_preview_plan.py dry-run.json preview.json --verify-run`. Report the added and modified counts. Repeat the read query and save `fresh.json`. Run `python skills/am-safe-change/scripts/family_preview_plan.py fresh.json preview.json --baseline`. Stop if either check fails.
7. Check the active family and policy again. Use Revit Keep or Discard under `ask`. Under `auto`, get the second approval after the dry run. After Discard, repeat the baseline check and stop. After Keep or an approved auto commit, save the full run as `kept.json`.
8. Run a separate read query on the staged family. Save the full response as `kept-read.json`. Run `python skills/am-safe-change/scripts/family_preview_plan.py kept-read.json preview.json --verify-kept kept.json`. Use Undo if the check fails. Save only after the check passes.
9. Open and activate the dedicated view. In **Save As > Options**, verify the preview source and regeneration. Save to the reviewed new output name. Stop if Revit prompts to overwrite. Rerun the staging verification with `--source-only` to check the source bytes.
10. Run `python -m pip install olefile==0.47` in a local virtual environment if olefile is unavailable. Run `python skills/am-model-health/scripts/stage_family_previews.py inspect-output <manifest-path> --family "Example.rfa" > saved-file.json`. Read the reported PNG status. A changed hash proves the image bytes differ. Inspect the rendered image before accepting the preset.
11. Reopen the exact output in Revit. Run `read_family_preview.py` as a query using the `revit_inputs` from `saved-file.json`. Save the full response as `saved-read.json`. Run `python skills/am-safe-change/scripts/family_preview_plan.py saved-read.json preview.json --verify-saved saved-file.json kept.json`.
12. Inspect the thumbnail in a fresh **Load Family** picker. Check the orientation, style and background against the preview. Record the Revit build, family and verification result. Record the returned reuse receipt only after the visual check passes. Keep a file whose thumbnail still needs review marked unverified.

Run `inspect-output <manifest-path>` without `--family` to check every staged name after saving the batch. An incomplete report lists missing outputs, missing thumbnails, and file checks that failed. Reopen and visually check every saved family before accepting the batch.
